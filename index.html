为真实考试而生

覆盖从单选题到解答题的完整题型，排版细节都可控。

🧩

模块化题型

选择题 / 填空题 / 解答题 / 考生信息 / 自定义区均为独立模块，可自由添加、复制、拖拽排序。

📄

固定纸张分页

纸张尺寸不随内容变化；内容自动按“第一面 → 第二面 → 第二页第一面”顺序填充，A3 每面双栏。

🔤

填涂 / 手写双样式

选择题支持中括号 [A] 填涂与横线手写两种作答样式，一行题数自动适配纸张宽度，绝不溢出。

✎

多级填空

支持 11（1）、11（2）①/② 这类多级小题；每个空长度、每题行间距均可调。

📐

解答题横线

解答题可选择空白大框或等距横线样式，横线间距可调，作答区高度按需设置。

🖨

一键打印 / PDF

浏览器直接打印或另存 PDF；支持双面长边翻转，模板可导出为 JSON 复用。

四步出一张答题卡

添加题型

2

拖动结构列表调整题目顺序。

3

配置属性

题数、样式、空格、字号、对齐。

4

打印导出

选纸张与双面，打印或存 PDF。

部署方式

纯静态站点，Docker 或任意 HTTP 服务器均可。

🐳 Docker

# 构建并运行
docker build -t answer-sheet-builder .
docker run -d --name asb -p 8080:80 \
  answer-sheet-builder

# 或使用 compose
docker compose up -d

💻 本地 / 任意服务器

# 纯静态，任选一种
python3 -m http.server 8080
# 浏览器打开
http://localhost:8080/app.html
